Computer Vision Case Study

VisionGuard AI

A safety-monitoring prototype that brings camera operations, live views, alerts, evidence, and computer-vision integrations into one local workflow.

Current Graduation ProjectIn active development
PROJECT IDVG / 2026Local / LAN prototype

System architecture

A practical vision workflow, end to end.

What is implemented

  • Authenticated, workspace-aware camera operations
  • Camera configuration and connection checks
  • Live MJPEG streaming workflows
  • Persisted alerts and evidence handling
  • Model-capability reporting and CPU-based face matching

Technology

React Native, Expo Router, TypeScript, Python, Flask, SQLite, OpenCV, TensorFlow and Ultralytics integrations, with InsightFace and ONNX Runtime components in the local prototype.

Status note

VisionGuard AI is an active local/LAN prototype. This portfolio describes the implemented workflow without presenting it as a hosted production system.
