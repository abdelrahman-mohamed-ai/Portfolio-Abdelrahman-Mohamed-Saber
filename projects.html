01 Graduation project

VisionGuard AI · Current graduation project

Safety monitoring with a local camera gateway.

VisionGuard AI is the current graduation project. It combines an Expo / React Native interface with a local Python gateway for authenticated, workspace-aware camera operations. The implemented system covers camera configuration and connection checks, live MJPEG streaming, persisted alerts and evidence, model-capability reporting, and CPU-based face matching.

Implemented focus

  • Camera operations and live monitoring workflows
  • Alert and evidence handling with local persistence
  • Computer-vision integration points for OpenCV and supported models

Stack

React Native, Expo Router, TypeScript, Python, Flask, SQLite, OpenCV, TensorFlow / Ultralytics integrations.
